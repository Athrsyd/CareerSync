# 🚀 CareerSync

> **Bridging the gap between your skills and industry needs.**

CareerSync adalah platform berbasis web yang dirancang untuk membantu pelajar dan pencari kerja mengukur kesiapan kerja secara objektif, mengidentifikasi **skill gap**, serta membangun kemampuan praktis melalui pendekatan **project-based learning**.

CareerSync menjembatani kesenjangan antara **kemampuan individu** dan **kebutuhan industri** melalui analisis berbasis data, rekomendasi proyek, pemantauan perkembangan skill, dan AI-powered insights.

## 📌 Tentang Project

Salah satu tantangan dalam memasuki dunia kerja adalah adanya kesenjangan antara **skill yang dimiliki individu** dengan **skill yang dibutuhkan oleh industri**.

Pelajar dan pencari kerja sering kali mengetahui bidang pekerjaan yang mereka inginkan, tetapi belum mengetahui:

* Seberapa siap mereka untuk memasuki dunia kerja.
* Skill apa saja yang masih kurang.
* Skill mana yang harus diprioritaskan.
* Bagaimana cara meningkatkan skill tersebut melalui pengalaman praktis.
* Bagaimana membuktikan kemampuan mereka kepada calon pemberi kerja.

**CareerSync hadir untuk menjawab permasalahan tersebut.**

CareerSync membantu pengguna memahami posisi mereka saat ini, menemukan *skill gap*, mendapatkan rekomendasi pembelajaran berbasis proyek, serta membangun portfolio sebagai bukti kemampuan praktis.

Dengan demikian, pengguna tidak hanya mengetahui **"skill apa yang kurang"**, tetapi juga mendapatkan arahan mengenai **"apa yang harus dilakukan selanjutnya."**

# 🧮 Job Readiness Score

CareerSync menggunakan metode **Weighted Scoring** untuk menghasilkan skor kesiapan kerja berdasarkan tingkat kepentingan setiap skill.

$$
\text{Job Readiness Score} =
\frac{\sum_{i=1}^{n}(b_i \cdot L_i)}
{\sum_{i=1}^{n}(b_i \cdot L_{max})}
\times 100\%
$$

### Variabel

| Variabel | Keterangan                                |
| -------- | ----------------------------------------- |
| `bᵢ`     | Bobot atau tingkat kepentingan skill ke-i |
| `Lᵢ`     | Level skill yang dimiliki pengguna        |
| `Lmax`   | Level maksimum skill                      |
| `n`      | Jumlah skill yang dievaluasi              |

Pendekatan ini memungkinkan setiap skill memiliki tingkat kepentingan yang berbeda sesuai dengan kebutuhan karier yang dipilih pengguna.

Sebagai contoh, seorang pengguna yang ingin menjadi **Frontend Developer** dapat memiliki bobot yang lebih tinggi pada HTML, CSS, JavaScript, dan React dibandingkan skill lainnya.

# 🚀 Cara Menjalankan Project

## Prerequisites

* Node.js >= 18
* npm atau yarn

## Installation

```bash
# Clone repository
git clone https://github.com/[username]/careersync.git

# Masuk ke project
cd careersync

# Masuk ke frontend
cd Frontend

# Install dependencies
npm install

# Jalankan development server
npm run dev
```

Frontend akan berjalan pada:

```text
http://localhost:5173
```
